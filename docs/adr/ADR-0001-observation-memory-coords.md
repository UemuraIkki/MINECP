# ADR-0001: 記憶座標はブリッジ側で保持し、observationメッセージに含めない

- 状態: 承認
- 日付: 2026-07-24

## 文脈

仕様書§5の観測仕様には「記憶座標(拠点、ネザーポータル、要塞、直近の死亡地点)」が含まれる。一方§4.2ではこれらの座標記憶はブリッジの責務とされており、Modは判断ロジックも長期記憶も持たない(§4.1)。

## 決定

- Mod → ブリッジの `observation` メッセージには記憶座標を**含めない**。Modが知り得るのは現在状態のみとする。
- ブリッジは、死亡イベント(`event: death`)や自身が発行したスキル結果(ポータル建設成功等)から記憶座標を更新・永続化する。
- §5の「観測」は**LLMに提示するコンテキスト**の仕様として解釈する。ブリッジがModからのobservationと自身の記憶座標をマージしてLLMプロンプトを構築する。

## 帰結

- Modはステートレスに近く保たれ、スキーマも小さくなる。
- 拠点座標の初期値は、ブリッジがFake Playerの初期スポーン地点(初回observationの座標)を拠点として登録する。
